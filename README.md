# 🎓 Campus Cloud

Campus Cloud is a Student Community Platform developed using Flask.

## 🚀 Features

- Student Login & Registration
- Admin Dashboard
- Student Dashboard
- Study Notes
- Guess Papers
- Notice Board
- Lost & Found
- Expense Tracker
- Parent Portal
- Teacher Portal

## 🛠 Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
